# 🚆 Global Airport Transit Explorer

**Live Demo:** [https://city-airport-transit-viz.streamlit.app/](https://city-airport-transit-viz.streamlit.app/)

Welcome to the interactive infographic exploring major airport express connections, focusing primarily on Southeast Asia!

Compare how quickly and efficiently you can get from the terminal to the city center using this interactive Streamlit application.

## Features
- **🎯 Radial Map:** Standardizes geography to compare airport distances from the city center.
- **📏 Dumbbell Chart:** Direct distance and time comparison.
- **🔀 Transfer Focus:** Visualizes route segments, train lines, and transit operators.
- **📋 Detailed Data Grid:** View and sort comprehensive transit data including speeds and pricing.

## Built With
- Python
- Streamlit
- Pandas
- Plotly
